# 小爱场景智能编排与自愈 Agent (XiaoAi Scene Composer)

基于多 Agent 协作的智能家居场景自动化生成与冲突自愈系统。

## 痛点
- 米家场景创建需要用户手动配置“如果…就执行…”，学习成本高
- 复杂场景（如“离家模式”同时涉及灯光、空调、安防）配置易产生规则冲突，导致场景不触发或设备异常
- 传统的人工编写场景耗时且无法自动适应设备变动

## 核心逻辑流（4 Agent 长链推理 + 闭环验证）
1. **需求解析 Agent** – 将自然语言需求转化为结构化场景意图（触发条件、执行动作、涉及设备）
2. **设备能力 Agent** – 查询家庭设备列表、能力、当前状态，建立设备能力图谱
3. **场景编排 Agent** – 基于用户意图和设备能力，生成符合小米规则引擎的 JSON 场景定义，并检查是否存在冲突（如死循环、权限不足）
4. **闭环验证 Agent** – 在模拟环境中执行该场景，监控设备状态变化，若未达预期则回溯到编排 Agent 重新生成，直到验证通过或给出失败原因

整个过程是 **“意图→生成→验证→修正”** 的长链推理循环，一次复杂场景编排平均调用工具 7-10 次。

## 落地效果
- 已部署在个人小米智能家庭环境中，管理 35+ 设备
- 成功生成 20+ 个复杂场景（离家、回家、睡眠、观影等）
- 场景生成时间从人工平均 12 分钟降至 28 秒
- 场景冲突率由 15% 降至 1% 以下
- 日 Token 消耗约 220 万（DeepSeek + Claude 混合路由）

## 技术栈
- Agent 框架：自研轻量调度器，兼容 OpenAI Function Calling
- 模型：Claude 3.5 / DeepSeek-V3
- 工具模拟：小米 IoT 场景引擎 API 封装
